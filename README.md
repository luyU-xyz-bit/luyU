# LuaU Web IDE

A comprehensive web-based IDE for LuaU coding with obfuscation, script publishing, and advanced features.

## Features

- Code Editor with LuaU syntax highlighting
- Loadstring & Obfuscation tools
- Compiler & Converter to .lua files
- Live Console for testing
- Undo/Redo (⟲ ⟳) & Clear (🗑️)
- Script publishing with tags
- PNG thumbnails support
- Anti-porn/gore content detection
- Key protection system
- Script marketplace

## Tech Stack

- React 18 + TypeScript
- Monaco Editor
- Node.js + Express
- MongoDB
- NSFWJS for content moderation

## Quick Start

```bash
npm install
npm run dev
```

Visit http://localhost:3000
